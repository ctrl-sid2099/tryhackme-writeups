## 🧭 Methodology

Most writeups follow this general workflow:

1. **Reconnaissance & Enumeration**

   * Nmap scans
   * Service detection
   * Directory brute-forcing

2. **Vulnerability Identification**

   * Analyzing services
   * Finding misconfigurations
   * Researching exploits

3. **Exploitation**

   * Gaining initial access
   * Using public or custom exploits

4. **Privilege Escalation**

   * LinPEAS / WinPEAS
   * Manual enumeration
   * Exploiting weak permissions or misconfigs

5. **Post Exploitation**

   * Proof of access
   * Flags capture
   * System understanding
