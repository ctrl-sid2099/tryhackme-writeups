## 📖 About This Repository

Welcome to my **TryHackMe SOC Level 1 Writeups Repository**.

This repository contains detailed walkthroughs, investigations, and analyses of rooms completed during the **SOC Level 1 Path** on TryHackMe.

Unlike simple solution-based writeups, these notes focus on:

✅ Incident Analysis
✅ Threat Investigation Methodology
✅ Log Analysis & Correlation
✅ SIEM Queries & Hunting Techniques
✅ Tool Usage & Practical Applications
✅ Detection Engineering Concepts
✅ MITRE ATT&CK Mapping
✅ IOC Identification & Validation
✅ Blue Team Thinking Process
✅ Detailed Explanations of Findings

The goal is to document not only **what was done**, but also **why it was done** and **how the findings were derived**.
